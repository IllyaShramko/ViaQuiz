# viaquiz-minimal-pro-ui

Project-local skill for designing, auditing, and refactoring any UI view across ViaQuiz using the **Minimal Pro (Linear-style)** design system.

## Location

`.agents/skills/viaquiz-minimal-pro-ui/`

## Contents

- `SKILL.md` — Core workflow, token cheat sheet, and verification steps
- `references/anti-slop-checklist.md` — Visual audit checklist for catching and replacing generic "AI-slop" patterns
- `references/patterns.md` — Verified ViaQuiz CSS & JSX patterns for containers, segmented tabs, tables, cards, and context bars

## Typical Usage

- Auditing screenshots or existing pages anywhere in the app and proposing cleaner Minimal Pro alternatives
- Refactoring legacy or inconsistent page styles into clean, component-scoped `.module.css` layouts
- Building new screens, modals, tables, dashboards, and interactive views with a consistent ViaQuiz look and feel
